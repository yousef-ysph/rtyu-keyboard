# RTYU - RP2040 based split keyboard

RTYU is a 54 custom split ortho-linear keyboard inspired by [silakka54](https://github.com/Squalius-cephalus/silakka54).
RTYU uses hot-swap sockets for low profile choc v2 or cherry mx keyswitches (depending on the pcb)

Firmware is based on [QMK](https://github.com/qmk/qmk_firmware) and there is a [Vial](https://github.com/vial-kb/vial-qmk) port for Vial GUI app
